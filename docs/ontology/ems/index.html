EMS - Effort Management System Ontology

https://exocortex.my/ontology/ems#

Effort Management System Ontology provides vocabulary for task management, project planning, and effort tracking.

Key concepts: Tasks, Projects, Areas, Ideas, Sessions, Meetings, and OKRs with status tracking and timestamps.
