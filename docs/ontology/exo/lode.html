Preferred Namespace Prefix

Preferred Namespace Uri

Description

Core ontology for Exocortex knowledge management system. Defines fundamental concepts: Assets, Classes, Properties, Instances, and their relationships. Provides interoperability with standard RDF/RDFS/OWL vocabularies.
