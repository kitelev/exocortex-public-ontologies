EXO - Exocortex Core Ontology

https://exocortex.my/ontology/exo#

Exocortex Core Ontology defines fundamental concepts for knowledge management: Assets, Classes, Properties, Instances, and their relationships.

This ontology provides interoperability with standard RDF/RDFS/OWL vocabularies through rdfs:subClassOf and rdfs:subPropertyOf mappings.
