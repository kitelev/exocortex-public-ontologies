Developer Learning Path

Learn to build applications that use semantic data. Start with RDF basics, then explore domain vocabularies relevant to your project.

1

Understand the Triple Model Beginner

Learn how RDF represents data as subject-predicate-object triples. This is the foundation of everything.

RDF/RDFS/OWL Guide RDF Reference
2

Learn RDFS Schemas Beginner

Understand how to define classes, properties, and their relationships using RDFS.

RDFS Reference Class Hierarchy
3

Try SPARQL Queries Beginner

Query semantic data using SPARQL. Start with simple SELECT queries, then move to more complex patterns.

SPARQL Playground
4

Model People with FOAF Intermediate

Use the Friend of a Friend vocabulary to describe users, their relationships, and social connections.

FOAF Guide FOAF Examples FOAF Reference
5

Add Metadata with Dublin Core Intermediate

Describe resources with standard metadata: title, creator, date, description, etc.

Dublin Core Guide DC Terms Reference
6

Validate with SHACL Advanced

Define shapes to validate that your RDF data conforms to expected patterns.

SHACL Reference
⏱️
Estimated time: 4-6 hours
Core steps 1-5, plus optional SHACL

Data Scientist Learning Path

Focus on querying and analyzing linked data. Learn to navigate complex relationships and extract insights from knowledge graphs.

1

RDF Data Model Basics Beginner

Understand how RDF structures data differently from tables. Learn about URIs, literals, and blank nodes.

RDF/RDFS/OWL Guide Getting Started
2

Master SPARQL Intermediate

Learn to write powerful queries: JOINs via pattern matching, aggregations, subqueries, OPTIONAL patterns.

SPARQL Playground
3

Understand Class Hierarchies Intermediate

Learn to traverse rdfs:subClassOf relationships. Understand how inference expands query results.

Class Hierarchy Browser rdfs:subClassOf
4

Work with Datasets (DCAT) Intermediate

Describe datasets, distributions, and data services using the Data Catalog vocabulary.

DCAT Guide DCAT Examples DCAT Reference
5

Quantities and Units (QUDT) Intermediate

Handle scientific measurements with proper units and quantity kinds for accurate analysis.

QUDT Guide QUDT Examples QUDT Reference
6

Track Data Provenance Advanced

Record where data came from, how it was transformed, and who was responsible.

PROV-O Guide Provenance Examples
⏱️
Estimated time: 5-8 hours
Deep SPARQL focus with domain vocabularies

Researcher Learning Path

Model complex domains with formal semantics. Learn to create ontologies that enable automated reasoning and ensure reproducibility.

1

From RDF to OWL Beginner

Understand the progression from simple triples (RDF) to schemas (RDFS) to full ontologies (OWL).

RDF/RDFS/OWL Guide OWL Reference
2

Master OWL Constructs Intermediate

Learn property characteristics, class expressions, restrictions, and equivalences.

owl:TransitiveProperty owl:Restriction owl:equivalentClass
3

Model Time with OWL-Time Intermediate

Represent temporal entities, intervals, durations, and temporal relationships.

OWL-Time Guide TIME Examples TIME Reference
4

Track Provenance with PROV-O Intermediate

Document how your data was created, transformed, and validated for reproducibility.

PROV-O Guide Provenance Examples PROV-O Reference
5

Sensor Data with SOSA/SSN Intermediate

Model observations, sensors, and measurements for scientific data collection.

SOSA/SSN Guide SOSA Reference
6

Validate with SHACL Advanced

Create validation rules to ensure data quality and constraint satisfaction.

SHACL Reference
⏱️
Estimated time: 8-12 hours
Comprehensive ontology modeling skills

Enterprise Architect Learning Path

Design data integration architectures using semantic standards. Learn how ontologies enable interoperability across systems.

1

Semantic Web Foundations Beginner

Understand the semantic web stack and how it enables data integration.

RDF/RDFS/OWL Guide Getting Started
2

Organizational Modeling (ORG) Intermediate

Model organizations, departments, memberships, and organizational roles.

ORG Guide ORG Examples ORG Reference
3

Taxonomy Management (SKOS) Intermediate

Create and manage classification schemes, thesauri, and controlled vocabularies.

SKOS Guide SKOS Examples SKOS Reference
4

Data Catalog Standards (DCAT) Intermediate

Describe data assets, services, and their distributions for enterprise data catalogs.

DCAT Guide DCAT Examples
5

Metadata Standards Intermediate

Apply Dublin Core for consistent metadata across all enterprise resources.

Dublin Core Guide DC Terms Reference
6

Data Lineage (PROV-O) Advanced

Track data provenance for compliance and audit requirements.

PROV-O Guide Provenance Examples
⏱️
Estimated time: 6-10 hours
Enterprise integration and governance focus
