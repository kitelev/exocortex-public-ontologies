Describing a Person

FOAF

Use FOAF (Friend of a Friend) to describe people, their relationships, and online presence.

@prefix foaf: <http://xmlns.com/foaf/0.1/> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

:alice a foaf:Person ;
    foaf:name "Alice Smith" ;
    foaf:givenName "Alice" ;
    foaf:familyName "Smith" ;
    foaf:mbox <mailto:alice@example.com> ;
    foaf:homepage <https://alice.example.com> ;
    foaf:knows :bob, :carol ;
    foaf:interest <http://dbpedia.org/resource/Semantic_Web> .

:bob a foaf:Person ;
    foaf:name "Bob Jones" ;
    foaf:knows :alice .

Key classes: foaf:Person, foaf:Organization, foaf:Document

Key properties: foaf:name, foaf:knows, foaf:mbox

Geolocation Data

GEO Schema.org

Combine WGS84 Geo with Schema.org for rich location data.

@prefix geo: <http://www.w3.org/2003/01/geo/wgs84_pos#> .
@prefix schema: <https://schema.org/> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

:eiffelTower a schema:LandmarksOrHistoricalBuildings, geo:SpatialThing ;
    schema:name "Eiffel Tower"@en ;
    schema:name "Tour Eiffel"@fr ;
    schema:description "Iconic iron lattice tower in Paris" ;
    geo:lat "48.8584"^^xsd:float ;
    geo:long "2.2945"^^xsd:float ;
    geo:alt "330"^^xsd:float ;
    schema:address [
        a schema:PostalAddress ;
        schema:streetAddress "Champ de Mars, 5 Avenue Anatole France" ;
        schema:addressLocality "Paris" ;
        schema:postalCode "75007" ;
        schema:addressCountry "FR"
    ] .

Key classes: geo:SpatialThing, geo:Point

Key properties: geo:lat, geo:long, geo:alt

Temporal Events

TIME

Use OWL-Time to model temporal concepts: instants, intervals, durations.

@prefix time: <http://www.w3.org/2006/time#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

:conference2024 a time:Interval ;
    time:hasBeginning :conf_start ;
    time:hasEnd :conf_end ;
    time:hasDuration [
        a time:Duration ;
        time:numericDuration "3"^^xsd:decimal ;
        time:unitType time:unitDay
    ] .

:conf_start a time:Instant ;
    time:inXSDDateTime "2024-09-15T09:00:00Z"^^xsd:dateTime .

:conf_end a time:Instant ;
    time:inXSDDateTime "2024-09-17T18:00:00Z"^^xsd:dateTime .

# Temporal relations
:keynote a time:Interval ;
    time:intervalDuring :conference2024 ;
    time:hasBeginning [
        a time:Instant ;
        time:inXSDDateTime "2024-09-15T10:00:00Z"^^xsd:dateTime
    ] .

Key classes: time:Instant, time:Interval, time:Duration

Data Provenance

PROV-O

Track data lineage with PROV-O: who created what, when, and how.

@prefix prov: <http://www.w3.org/ns/prov#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

# The dataset is an Entity
:sales_report_v2 a prov:Entity ;
    prov:wasGeneratedBy :data_processing ;
    prov:generatedAtTime "2024-01-15T14:30:00Z"^^xsd:dateTime ;
    prov:wasDerivedFrom :sales_data_raw ;
    prov:wasAttributedTo :alice .

# The processing is an Activity
:data_processing a prov:Activity ;
    prov:startedAtTime "2024-01-15T14:00:00Z"^^xsd:dateTime ;
    prov:endedAtTime "2024-01-15T14:30:00Z"^^xsd:dateTime ;
    prov:used :sales_data_raw ;
    prov:wasAssociatedWith :alice ;
    prov:used :etl_script_v3 .

# Alice is an Agent
:alice a prov:Agent, prov:Person ;
    prov:actedOnBehalfOf :data_team .

:data_team a prov:Agent, prov:Organization .

Key classes: prov:Entity, prov:Activity, prov:Agent

Key properties: prov:wasDerivedFrom, prov:wasGeneratedBy

Organizational Structure

ORG FOAF

Model organizations, departments, and roles with W3C Organization Ontology.

@prefix org: <http://www.w3.org/ns/org#> .
@prefix foaf: <http://xmlns.com/foaf/0.1/> .

:acme_corp a org:FormalOrganization ;
    foaf:name "ACME Corporation" ;
    org:hasUnit :engineering_dept, :sales_dept ;
    org:hasSite :hq_office .

:engineering_dept a org:OrganizationalUnit ;
    foaf:name "Engineering Department" ;
    org:unitOf :acme_corp ;
    org:hasPost :cto_post, :dev_lead_post .

:cto_post a org:Post ;
    org:role :cto_role ;
    org:heldBy :john .

:john a foaf:Person ;
    foaf:name "John Smith" ;
    org:memberOf :acme_corp ;
    org:headOf :engineering_dept .

:hq_office a org:Site ;
    org:siteOf :acme_corp ;
    org:siteAddress [
        a vcard:Address ;
        vcard:locality "San Francisco"
    ] .

Key classes: org:Organization, org:OrganizationalUnit, org:Post

Building a Taxonomy

SKOS

Create controlled vocabularies and taxonomies with SKOS.

@prefix skos: <http://www.w3.org/2004/02/skos/core#> .

:ProductCategories a skos:ConceptScheme ;
    skos:prefLabel "Product Categories"@en ;
    skos:hasTopConcept :Electronics, :Clothing .

:Electronics a skos:Concept ;
    skos:prefLabel "Electronics"@en ;
    skos:altLabel "Electronic Devices"@en ;
    skos:definition "Devices that operate using electrical power"@en ;
    skos:topConceptOf :ProductCategories ;
    skos:narrower :Computers, :Phones .

:Computers a skos:Concept ;
    skos:prefLabel "Computers"@en ;
    skos:broader :Electronics ;
    skos:narrower :Laptops, :Desktops ;
    skos:related :Software .

:Laptops a skos:Concept ;
    skos:prefLabel "Laptops"@en ;
    skos:prefLabel "Notebook Computers"@en ;
    skos:broader :Computers ;
    skos:scopeNote "Portable computers with integrated screen"@en .

Key classes: skos:Concept, skos:ConceptScheme

Key properties: skos:broader, skos:narrower, skos:related

Dataset Metadata

DCAT

Describe datasets and data catalogs with DCAT.

@prefix dcat: <http://www.w3.org/ns/dcat#> .
@prefix dcterms: <http://purl.org/dc/terms/> .
@prefix foaf: <http://xmlns.com/foaf/0.1/> .

:open_data_portal a dcat:Catalog ;
    dcterms:title "City Open Data Portal"@en ;
    dcterms:publisher :city_gov ;
    dcat:dataset :traffic_data, :crime_stats .

:traffic_data a dcat:Dataset ;
    dcterms:title "Traffic Flow Data 2024"@en ;
    dcterms:description "Real-time traffic sensor readings"@en ;
    dcterms:issued "2024-01-01"^^xsd:date ;
    dcterms:modified "2024-01-15"^^xsd:date ;
    dcterms:publisher :city_gov ;
    dcat:keyword "traffic", "transportation", "sensors" ;
    dcat:distribution :traffic_csv, :traffic_api .

:traffic_csv a dcat:Distribution ;
    dcterms:title "CSV Download" ;
    dcat:downloadURL <https://data.city.gov/traffic/2024.csv> ;
    dcat:mediaType "text/csv" ;
    dcat:byteSize "15000000"^^xsd:integer .

:traffic_api a dcat:Distribution ;
    dcterms:title "REST API" ;
    dcat:accessURL <https://api.city.gov/traffic/> ;
    dcat:mediaType "application/json" .

Key classes: dcat:Catalog, dcat:Dataset, dcat:Distribution

Scientific Measurements

QUDT

Express quantities with units using QUDT (Quantities, Units, Dimensions, Types).

@prefix qudt: <http://qudt.org/schema/qudt/> .
@prefix unit: <http://qudt.org/vocab/unit/> .
@prefix quantitykind: <http://qudt.org/vocab/quantitykind/> .

:sensor_reading_001 a qudt:Quantity ;
    qudt:hasQuantityKind quantitykind:Temperature ;
    qudt:numericValue "25.5"^^xsd:double ;
    qudt:unit unit:DEG_C .

:distance_measurement a qudt:Quantity ;
    qudt:hasQuantityKind quantitykind:Length ;
    qudt:numericValue "42.195"^^xsd:double ;
    qudt:unit unit:KiloM .

:power_output a qudt:Quantity ;
    qudt:hasQuantityKind quantitykind:Power ;
    qudt:numericValue "1.21"^^xsd:double ;
    qudt:unit unit:GigaW .
Note: QUDT includes 1,000+ predefined units and quantity kinds. Browse the full catalog at QUDT and QuantityKinds.

Key classes: qudt:Quantity, qudt:Unit

Combining Multiple Ontologies

Real-world data often requires combining multiple ontologies. Here's an example that integrates several vocabularies:

@prefix foaf: <http://xmlns.com/foaf/0.1/> .
@prefix org: <http://www.w3.org/ns/org#> .
@prefix prov: <http://www.w3.org/ns/prov#> .
@prefix geo: <http://www.w3.org/2003/01/geo/wgs84_pos#> .
@prefix dcterms: <http://purl.org/dc/terms/> .
@prefix time: <http://www.w3.org/2006/time#> .

# A research paper with full provenance and authorship
:paper_2024 a prov:Entity, foaf:Document ;
    dcterms:title "Semantic Web Advances 2024" ;
    dcterms:created "2024-03-15"^^xsd:date ;
    prov:wasAttributedTo :alice ;
    prov:wasGeneratedBy :research_project ;
    dcterms:subject <http://dbpedia.org/resource/Semantic_Web> .

:alice a foaf:Person, prov:Agent ;
    foaf:name "Dr. Alice Smith" ;
    org:memberOf :university ;
    foaf:based_near :campus_location .

:university a org:FormalOrganization ;
    foaf:name "Technical University" .

:campus_location a geo:SpatialThing ;
    geo:lat "52.5200" ;
    geo:long "13.4050" .

:research_project a prov:Activity ;
    time:hasBeginning [ time:inXSDDate "2023-01-01"^^xsd:date ] ;
    time:hasEnd [ time:inXSDDate "2024-03-01"^^xsd:date ] .
