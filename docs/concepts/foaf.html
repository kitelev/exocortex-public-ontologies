Understanding FOAF

10 min read • Beginner • Vocabulary

FOAF (Friend of a Friend) is one of the oldest and most widely-used ontologies on the semantic web. It describes people, their activities, and the relationships between them.

Core Classes

  • foaf:Agent (anything that can act)
    • foaf:Person
    • foaf:Organization
    • foaf:Group
  • foaf:Document
    • foaf:Image
    • foaf:PersonalProfileDocument
  • foaf:Project
  • foaf:OnlineAccount

Describing People

The most common use of FOAF is describing individuals:

@prefix foaf: <http://xmlns.com/foaf/0.1/> .

:alice a foaf:Person ;
    foaf:name "Alice Smith" ;
    foaf:givenName "Alice" ;
    foaf:familyName "Smith" ;
    foaf:mbox <mailto:alice@example.org> ;
    foaf:homepage <https://alice.example.org/> ;
    foaf:img <https://alice.example.org/photo.jpg> ;
    foaf:based_near <http://dbpedia.org/resource/Berlin> .
Privacy Consideration

FOAF was designed for the open web. Use foaf:mbox_sha1sum (a hash of email) instead of foaf:mbox when you want to identify someone without exposing their email address.

Key Properties

Identity Properties

Property Description Example
foaf:name Full name "Alice Smith"
foaf:givenName First name "Alice"
foaf:familyName Last name "Smith"
foaf:nick Nickname "asmith"
foaf:title Title/honorific "Dr."

Contact Properties

Property Range Note
foaf:mbox URI (mailto:) Inverse-functional (unique identifier)
foaf:mbox_sha1sum Literal SHA1 hash of email for privacy
foaf:homepage Document Personal website
foaf:weblog Document Blog
foaf:phone URI (tel:) Phone number

Social Connections

The foaf:knows property links people:

:alice foaf:knows :bob .
:bob foaf:knows :alice .  # Not automatically symmetric!

# With more detail
:alice foaf:knows [
    a foaf:Person ;
    foaf:name "Bob Jones" ;
    foaf:homepage <https://bob.example.org/>
] .
Note on foaf:knows

foaf:knows is intentionally vague — it means "has met" or "is somehow connected to." For more specific relationships, use vocabularies like RELATIONSHIP or extend FOAF with your own properties.

Online Accounts

Link people to their social media profiles:

:alice foaf:account [
    a foaf:OnlineAccount ;
    foaf:accountServiceHomepage <https://twitter.com/> ;
    foaf:accountName "alice_tweets"
] .

# Or use subclasses for common services
:alice foaf:account [
    a foaf:OnlineChatAccount ;
    foaf:accountServiceHomepage <https://slack.com/> ;
    foaf:accountName "alice.smith"
] .

Projects and Interests

# A project
:semanticWeb a foaf:Project ;
    foaf:name "Semantic Web Initiative" ;
    foaf:homepage <https://www.w3.org/2001/sw/> .

# Person's involvement
:alice foaf:currentProject :semanticWeb ;
       foaf:pastProject :oldProject ;
       foaf:interest <http://dbpedia.org/resource/Linked_data> ;
       foaf:topic_interest <http://dbpedia.org/resource/RDF> .

Organizations and Groups

:acme a foaf:Organization ;
    foaf:name "ACME Corporation" ;
    foaf:homepage <https://acme.example.org/> ;
    foaf:member :alice ;
    foaf:member :bob .

:devTeam a foaf:Group ;
    foaf:name "Development Team" ;
    foaf:member :alice ;
    foaf:member :charlie .

Complete Example: Professional Profile

@prefix foaf: <http://xmlns.com/foaf/0.1/> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .

:alice a foaf:Person ;
    # Identity
    foaf:name "Dr. Alice Smith" ;
    foaf:title "Dr." ;
    foaf:givenName "Alice" ;
    foaf:familyName "Smith" ;
    foaf:nick "asmith" ;

    # Contact
    foaf:mbox <mailto:alice@example.org> ;
    foaf:homepage <https://alice.example.org/> ;
    foaf:weblog <https://alice.example.org/blog/> ;

    # Visual
    foaf:img <https://alice.example.org/photo.jpg> ;
    foaf:depiction <https://alice.example.org/avatar.png> ;

    # Location
    foaf:based_near <http://dbpedia.org/resource/Berlin> ;

    # Work
    foaf:workplaceHomepage <https://university.example.org/> ;
    foaf:currentProject :semanticWebProject ;

    # Social
    foaf:knows :bob, :charlie ;

    # Online presence
    foaf:account [
        a foaf:OnlineAccount ;
        foaf:accountServiceHomepage <https://github.com/> ;
        foaf:accountName "alicesmith"
    ] ;

    # Interests
    foaf:interest <http://dbpedia.org/resource/Semantic_Web> ;
    foaf:interest <http://dbpedia.org/resource/Knowledge_graph> .

# Her employer
:acmeResearch a foaf:Organization ;
    foaf:name "ACME Research Lab" ;
    foaf:member :alice .

Integration with Other Ontologies

  • ORG — For detailed organizational structures (departments, roles)
  • vCard — For detailed address and contact information
  • PROV-O — Use foaf:Person as a prov:Agent
  • Schema.org — foaf:Person is compatible with schema:Person
  • DOAP — For software projects (maintainer, developer)
