Understanding OWL-Time

12 min read • Intermediate • Domain Ontology

OWL-Time is a W3C ontology for describing temporal concepts. It goes beyond simple timestamps to model complex temporal relationships, durations, and calendar systems.

When to Use OWL-Time vs. XSD Dates

Use XSD Datatypes When... Use OWL-Time When...
Simple timestamps suffice Modeling time intervals (start + end)
Precision is exact (2024-01-15T10:30:00Z) Dates are imprecise ("sometime in 2024")
No need to reason about time Querying temporal relationships (before, during, overlaps)
Standard Gregorian calendar only Multiple calendar systems needed

Core Concepts

Instants vs. Intervals

OWL-Time distinguishes between points and spans:

Instant
Interval
Instant
@prefix time: <http://www.w3.org/2006/time#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

# An instant (point in time)
:moonLanding a time:Instant ;
    time:inXSDDateTimeStamp "1969-07-20T20:17:00Z"^^xsd:dateTimeStamp .

# An interval (period of time)
:apolloMission a time:Interval ;
    time:hasBeginning :missionStart ;
    time:hasEnd :missionEnd .

:missionStart a time:Instant ;
    time:inXSDDateTimeStamp "1969-07-16T13:32:00Z"^^xsd:dateTimeStamp .

:missionEnd a time:Instant ;
    time:inXSDDateTimeStamp "1969-07-24T16:50:35Z"^^xsd:dateTimeStamp .

Durations

Express how long something lasts:

# Using XSD duration
:meeting time:hasDuration [
    a time:Duration ;
    time:numericDuration 1.5 ;
    time:unitType time:unitHour
] .

# Or using XSD duration directly
:meeting time:hasDuration "PT1H30M"^^xsd:duration .

Temporal Relations

OWL-Time provides Allen's interval algebra for precise temporal reasoning:

Relation Meaning Diagram
time:before X ends before Y starts |--X--|    |--Y--|
time:after X starts after Y ends |--Y--|    |--X--|
time:meets X ends exactly when Y starts |--X--|--Y--|
time:overlaps X starts before Y but ends during Y |--X--|
   |--Y--|
time:during X is entirely within Y |----Y----|
  |--X--|
time:contains Y is entirely within X |----X----|
  |--Y--|
time:equals Same start and end |--X--|
|--Y--|		 
# The meeting is before the deadline
:planningMeeting time:before :projectDeadline .

# Q1 contains January
:q1_2024 time:contains :january_2024 .

# Lunch overlaps with the presentation
:lunchBreak time:overlaps :presentation .

Date-Time Descriptions

For calendar-based representations:

:january_15_2024 a time:DateTimeDescription ;
    time:year 2024 ;
    time:month time:January ;
    time:day 15 ;
    time:dayOfWeek time:Monday ;
    time:unitType time:unitDay .
Named Months and Days

OWL-Time provides named individuals for months (time:January through time:December) and days of week (time:Monday through time:Sunday). This enables SPARQL queries like "find all events on Mondays."

Imprecise Dates

Not all dates are exact. OWL-Time handles this:

# "Sometime in 2024" - precision is year
:futureEvent a time:Instant ;
    time:inDateTime [
        a time:DateTimeDescription ;
        time:year 2024 ;
        time:unitType time:unitYear  # Only year-level precision
    ] .

# "In the 18th century"
:historicalEvent a time:Interval ;
    time:hasBeginning [ time:inXSDgYear "1701"^^xsd:gYear ] ;
    time:hasEnd [ time:inXSDgYear "1800"^^xsd:gYear ] .

Time Zones and Reference Systems

:localEvent a time:Instant ;
    time:inDateTime [
        a time:DateTimeDescription ;
        time:year 2024 ;
        time:month time:March ;
        time:day 15 ;
        time:hour 14 ;
        time:minute 30 ;
        time:timeZone <https://www.timeanddate.com/time/zones/cet>
    ] .

Complete Example: Conference Schedule

@prefix time: <http://www.w3.org/2006/time#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .
@prefix : <http://example.org/conference/> .

# The conference (3-day interval)
:semanticWeb2024 a time:Interval ;
    time:hasBeginning :day1_start ;
    time:hasEnd :day3_end ;
    time:hasDuration [
        a time:Duration ;
        time:numericDuration 3 ;
        time:unitType time:unitDay
    ] .

:day1_start a time:Instant ;
    time:inXSDDateTimeStamp "2024-05-15T09:00:00+02:00"^^xsd:dateTimeStamp .

:day3_end a time:Instant ;
    time:inXSDDateTimeStamp "2024-05-17T18:00:00+02:00"^^xsd:dateTimeStamp .

# A keynote speech (during the conference)
:keynote a time:Interval ;
    time:hasBeginning [
        a time:Instant ;
        time:inXSDDateTimeStamp "2024-05-15T09:30:00+02:00"^^xsd:dateTimeStamp
    ] ;
    time:hasDuration [
        a time:Duration ;
        time:numericDuration 45 ;
        time:unitType time:unitMinute
    ] .

# Temporal relation: keynote is during the conference
:keynote time:during :semanticWeb2024 .

# Coffee break meets (immediately follows) the keynote
:coffeeBreak time:meets :keynote ;
    time:hasDuration [
        a time:Duration ;
        time:numericDuration 15 ;
        time:unitType time:unitMinute
    ] .

Integration with Other Ontologies

  • PROV-O — Uses OWL-Time for activity start/end times
  • SOSA/SSN — Observation timestamps and phenomena time
  • DCAT — Dataset temporal coverage
  • Schema.org — Event scheduling and opening hours

Key Classes Reference

Class Description
time:Instant A zero-duration temporal entity (point in time)
time:Interval A temporal entity with extent (duration)
time:Duration Description of temporal extent
time:DateTimeDescription Calendar-based time representation
time:TemporalUnit Units like second, minute, hour, day, month, year
