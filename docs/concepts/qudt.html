Understanding QUDT

15 min read • Intermediate • Units & Measurements

QUDT (Quantities, Units, Dimensions, and Types) is a comprehensive ontology for scientific and engineering quantities. It enables machine-readable representation of measurements with proper unit semantics.

The QUDT Model

Quantity Kind
What you're measuring
Length, Mass, Time
Unit
How you measure it
Meter, Kilogram, Second
Dimension
Physical dimension
L, M, T
Prefix
Scale factor
Kilo, Milli, Micro

Core Concepts

Quantity Kinds

A quantity kind represents what is being measured:

@prefix qudt: <http://qudt.org/schema/qudt/> .
@prefix quantitykind: <http://qudt.org/vocab/quantitykind/> .

# Using a standard quantity kind
:measurement1 a qudt:Quantity ;
    qudt:hasQuantityKind quantitykind:Length ;
    qudt:numericValue 5.5 ;
    qudt:unit unit:M .

Common quantity kinds:

Quantity Kind Symbol Units
quantitykind:Length L Meter, Foot, Mile
quantitykind:Mass M Kilogram, Pound, Tonne
quantitykind:Time T Second, Minute, Hour
quantitykind:Temperature Θ Kelvin, Celsius, Fahrenheit
quantitykind:ElectricCurrent I Ampere, Milliampere
quantitykind:Velocity L/T Meter per Second, Knot
quantitykind:Area L² Square Meter, Hectare

Units

Units belong to unit systems and have conversion factors:

@prefix unit: <http://qudt.org/vocab/unit/> .

# Meter - the base SI unit for length
unit:M a qudt:Unit ;
    qudt:hasQuantityKind quantitykind:Length ;
    qudt:symbol "m" ;
    qudt:conversionMultiplier 1.0 ;
    rdfs:label "Meter"@en .

# Kilometer - derived unit
unit:KiloM a qudt:Unit ;
    qudt:hasQuantityKind quantitykind:Length ;
    qudt:symbol "km" ;
    qudt:conversionMultiplier 1000.0 ;
    qudt:prefix prefix:Kilo ;
    rdfs:label "Kilometer"@en .

Recording Measurements

Simple Value with Unit

@prefix qudt: <http://qudt.org/schema/qudt/> .
@prefix unit: <http://qudt.org/vocab/unit/> .

:sensorReading a qudt:Quantity ;
    qudt:numericValue 23.5 ;
    qudt:unit unit:DEG_C .

:distance a qudt:Quantity ;
    qudt:numericValue 42.195 ;
    qudt:unit unit:KiloM .

Quantity Value Pattern

For more structured data:

:experiment1 a :Experiment ;
    :hasTemperature [
        a qudt:QuantityValue ;
        qudt:numericValue 298.15 ;
        qudt:unit unit:K ;
        qudt:hasQuantityKind quantitykind:Temperature
    ] ;
    :hasPressure [
        a qudt:QuantityValue ;
        qudt:numericValue 101.325 ;
        qudt:unit unit:KiloPA ;
        qudt:hasQuantityKind quantitykind:Pressure
    ] .

Unit Conversion

QUDT provides conversion factors through conversionMultiplier and conversionOffset:

valueSI = (value × multiplier) + offset 
# Celsius to Kelvin
unit:DEG_C a qudt:Unit ;
    qudt:conversionMultiplier 1.0 ;
    qudt:conversionOffset 273.15 .

# Fahrenheit to Kelvin
unit:DEG_F a qudt:Unit ;
    qudt:conversionMultiplier 0.5555555556 ;  # 5/9
    qudt:conversionOffset 255.3722222222 .    # 459.67 × 5/9
Conversion Example

To convert 20°C to Kelvin:
K = (20 × 1.0) + 273.15 = 293.15 K

To convert 68°F to Kelvin:
K = (68 × 0.5556) + 255.37 = 293.15 K

Dimensional Analysis

QUDT tracks physical dimensions using dimension vectors:

# Velocity = Length / Time
quantitykind:Velocity
    qudt:hasDimensionVector "L1 T-1" ;  # L¹ × T⁻¹
    qudt:applicableUnit unit:M-PER-SEC, unit:KiloM-PER-HR .

# Force = Mass × Acceleration = M × L / T²
quantitykind:Force
    qudt:hasDimensionVector "M1 L1 T-2" ;  # M¹ × L¹ × T⁻²
    qudt:applicableUnit unit:N, unit:LB_F .

Complete Example: Sensor Data

@prefix qudt: <http://qudt.org/schema/qudt/> .
@prefix quantitykind: <http://qudt.org/vocab/quantitykind/> .
@prefix unit: <http://qudt.org/vocab/unit/> .
@prefix sosa: <http://www.w3.org/ns/sosa/> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

# Weather station observation
:observation_2024_01_15 a sosa:Observation ;
    sosa:observedProperty quantitykind:Temperature ;
    sosa:hasFeatureOfInterest :location_berlin ;
    sosa:resultTime "2024-01-15T14:30:00Z"^^xsd:dateTime ;
    sosa:hasResult [
        a qudt:QuantityValue ;
        qudt:numericValue 5.2 ;
        qudt:unit unit:DEG_C ;
        qudt:hasQuantityKind quantitykind:Temperature
    ] .

# Additional measurements
:observation_2024_01_15
    :hasWindSpeed [
        a qudt:QuantityValue ;
        qudt:numericValue 15.3 ;
        qudt:unit unit:KiloM-PER-HR ;
        qudt:hasQuantityKind quantitykind:Velocity
    ] ;
    :hasHumidity [
        a qudt:QuantityValue ;
        qudt:numericValue 78 ;
        qudt:unit unit:PERCENT ;
        qudt:hasQuantityKind quantitykind:RelativeHumidity
    ] ;
    :hasPressure [
        a qudt:QuantityValue ;
        qudt:numericValue 1013.25 ;
        qudt:unit unit:HectoPA ;
        qudt:hasQuantityKind quantitykind:Pressure
    ] .

  • DCAT — Document dataset measurement units

QUDT Vocabularies

QUDT is split into multiple vocabularies:

Vocabulary Contents
qudt: Core schema (Quantity, Unit, QuantityKind classes)
quantitykind: 1,000+ quantity kinds (Length, Mass, Force...)
prefix: SI prefixes (Kilo, Milli, Nano...)
unit: 2,000+ units (not imported here)
