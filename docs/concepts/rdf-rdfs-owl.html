Understanding RDF, RDFS & OWL

15 min read • Beginner • Core Foundations

The semantic web is built on three foundational specifications that work together like building blocks. Each layer adds more expressive power for describing knowledge.

OWL (Web Ontology Language)
Rich constraints & reasoning
RDFS (RDF Schema)
Class hierarchies & types
RDF (Resource Description Framework)
Basic triples
URIs & Literals
Identifiers & values

RDF: The Foundation

RDF (Resource Description Framework) is the base layer. It provides a simple way to make statements about things using triples.

The Triple Model

Every RDF statement consists of three parts:

Part Role Example
Subject The thing being described :Shakespeare
Predicate The property or relationship :wrote
Object The value or related thing :Hamlet 
# Turtle syntax
:Shakespeare :wrote :Hamlet .
:Hamlet :hasGenre :Tragedy .
:Hamlet :publishedIn "1603"^^xsd:gYear .
Key Insight

RDF uses URIs (Uniform Resource Identifiers) to uniquely identify things. The prefix : is shorthand for a namespace like http://example.org/. This ensures that "Shakespeare" in your data refers to the same entity across the entire web.

What RDF Defines

The RDF namespace (rdf:) provides these core concepts:

  • rdf:type — Links an instance to its class ("is a")
  • rdf:Property — The class of all properties
  • rdf:Statement — Reification (statements about statements)
  • rdf:List, rdf:first, rdf:rest — Ordered collections

RDFS: Adding Structure

RDF Schema (RDFS) adds vocabulary for defining classes and properties. It's the simplest schema language for RDF.

Classes and Instances

# Define a class
:Person a rdfs:Class .

# Create an instance
:Shakespeare a :Person .

# Classes can have subclasses
:Author rdfs:subClassOf :Person .
:Shakespeare a :Author .  # Also a Person!

Properties with Domains and Ranges

# Define a property
:wrote a rdf:Property ;
    rdfs:domain :Author ;     # Subject must be an Author
    rdfs:range :Work .        # Object must be a Work

# Property hierarchies
:authored rdfs:subPropertyOf :created .
Domain & Range

Domain = "what type of thing can have this property?"
Range = "what type of value can this property have?"

If :wrote has domain :Author, then saying :X :wrote :Y implies :X a :Author.

Key RDFS Vocabulary

Term Purpose
rdfs:Class The class of all classes
rdfs:subClassOf Class inheritance
rdfs:subPropertyOf Property inheritance
rdfs:domain Property applies to this class
rdfs:range Property values are of this type
rdfs:label Human-readable name
rdfs:comment Human-readable description

OWL: Rich Ontologies

OWL (Web Ontology Language) adds powerful constructs for complex knowledge modeling. It enables automated reasoning.

What OWL Adds

Property Characteristics

# Symmetric: if A knows B, then B knows A
:knows a owl:SymmetricProperty .

# Transitive: if A contains B and B contains C, then A contains C
:contains a owl:TransitiveProperty .

# Functional: each subject has at most one value
:hasBirthDate a owl:FunctionalProperty .

# Inverse: :hasParent is the inverse of :hasChild
:hasParent owl:inverseOf :hasChild .

Class Expressions

# Union: Parent OR Guardian
:Caregiver owl:unionOf ( :Parent :Guardian ) .

# Intersection: must be BOTH
:WorkingParent owl:intersectionOf ( :Employee :Parent ) .

# Restriction: exactly 4 wheels
:Car rdfs:subClassOf [
    a owl:Restriction ;
    owl:onProperty :hasWheel ;
    owl:cardinality 4
] .

Equivalence and Difference

# Same individual, different URIs
:WilliamShakespeare owl:sameAs dbpedia:William_Shakespeare .

# Definitely different
:Hamlet owl:differentFrom :Macbeth .

# Equivalent classes (same extension)
:Human owl:equivalentClass :Person .

OWL Profiles

OWL has three profiles for different use cases:

Profile Use Case Reasoning Complexity
OWL EL Large taxonomies (SNOMED CT) Polynomial time
OWL QL Query answering over databases Polynomial time
OWL RL Rule-based systems Polynomial time
OWL DL Full expressivity Decidable, but worst-case exponential

Choosing the Right Layer

Need Use
Simple data interchange RDF only
Class hierarchies, basic types RDF + RDFS
Property characteristics (symmetric, transitive) OWL
Cardinality constraints OWL
Automated reasoning OWL
Practical Advice

Start with RDFS. Add OWL constructs only when you need them. Many real-world applications use "OWL Lite" — a subset that's easy to understand and implement.
