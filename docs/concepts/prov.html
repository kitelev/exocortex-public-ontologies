Understanding PROV-O

15 min read • Intermediate • Domain Ontology

PROV-O (Provenance Ontology) is a W3C standard for describing the history of data. It answers questions like: Where did this data come from? Who created it? What process produced it?

The Core Model

PROV-O is built around three core concepts:

Entity
←
Activity
←
Agent
Entity (data, documents)
Activity (processes)
Agent (people, software)
Concept Description Examples
prov:Entity A physical, digital, or conceptual thing Document, dataset, file, webpage
prov:Activity Something that happens over time Editing, transformation, analysis
prov:Agent Something that bears responsibility Person, organization, software

Key Relationships

Entity Derivation

When one entity is derived from another:

@prefix prov: <http://www.w3.org/ns/prov#> .

:report_v2 a prov:Entity ;
    prov:wasDerivedFrom :report_v1 ;
    prov:generatedAtTime "2024-01-15T14:30:00Z"^^xsd:dateTime .
Derivation Chain

wasDerivedFrom is transitive. If A was derived from B, and B from C, then A was (indirectly) derived from C. This lets you trace data lineage back to its origins.

Generation and Usage

Activities use entities and generate new ones:

:analysis a prov:Activity ;
    prov:used :raw_data ;           # Input
    prov:generated :report ;        # Output
    prov:startedAtTime "2024-01-15T10:00:00Z"^^xsd:dateTime ;
    prov:endedAtTime "2024-01-15T14:00:00Z"^^xsd:dateTime .

:report prov:wasGeneratedBy :analysis .

Attribution and Association

Connecting agents to their work:

:report prov:wasAttributedTo :alice .

:alice a prov:Agent, foaf:Person ;
    foaf:name "Alice Smith" .

:analysis prov:wasAssociatedWith :alice ;
    prov:wasAssociatedWith :analysis_software .

Complete Example: Document Workflow

@prefix prov: <http://www.w3.org/ns/prov#> .
@prefix foaf: <http://xmlns.com/foaf/0.1/> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

# The final report (Entity)
:final_report a prov:Entity ;
    prov:wasGeneratedBy :review_process ;
    prov:wasDerivedFrom :draft_report ;
    prov:wasAttributedTo :editor ;
    prov:generatedAtTime "2024-01-20T16:00:00Z"^^xsd:dateTime .

# The draft (Entity)
:draft_report a prov:Entity ;
    prov:wasGeneratedBy :writing_process ;
    prov:wasDerivedFrom :research_notes ;
    prov:wasAttributedTo :author .

# Writing activity
:writing_process a prov:Activity ;
    prov:used :research_notes ;
    prov:wasAssociatedWith :author ;
    prov:startedAtTime "2024-01-10T09:00:00Z"^^xsd:dateTime ;
    prov:endedAtTime "2024-01-15T17:00:00Z"^^xsd:dateTime .

# Review activity
:review_process a prov:Activity ;
    prov:used :draft_report ;
    prov:wasAssociatedWith :editor ;
    prov:startedAtTime "2024-01-16T09:00:00Z"^^xsd:dateTime ;
    prov:endedAtTime "2024-01-20T16:00:00Z"^^xsd:dateTime .

# Agents
:author a prov:Agent, prov:Person ;
    foaf:name "Alice Smith" .

:editor a prov:Agent, prov:Person ;
    foaf:name "Bob Jones" .

Specialized Concepts

Delegation

When one agent acts on behalf of another:

:alice prov:actedOnBehalfOf :acme_corp .
:automated_system prov:actedOnBehalfOf :alice .

Bundles

Named sets of provenance statements (provenance of provenance):

:provenance_record a prov:Bundle ;
    prov:wasAttributedTo :provenance_service ;
    prov:generatedAtTime "2024-01-21T00:00:00Z"^^xsd:dateTime .

Invalidation

Recording when entities become invalid:

:old_data prov:wasInvalidatedBy :cleanup_job ;
    prov:invalidatedAtTime "2024-02-01T00:00:00Z"^^xsd:dateTime .

Common Use Cases

Domain Use Case
Scientific Research Track which datasets were used to produce results, enable reproducibility
Data Governance Audit data transformations for compliance (GDPR, HIPAA)
Journalism Document sources and verification steps for stories
Software Track build artifacts back to source code and tools
Digital Archives Record custody and preservation actions on digital objects

Key Properties Reference

Property Domain Range Meaning
wasGeneratedBy Entity Activity Entity was created by activity
wasDerivedFrom Entity Entity Entity came from another entity
wasAttributedTo Entity Agent Agent is responsible for entity
used Activity Entity Activity used entity as input
wasAssociatedWith Activity Agent Agent was involved in activity
actedOnBehalfOf Agent Agent Agent acted for another agent

Integration with Other Ontologies

PROV-O works well with:

  • OWL-Time — For complex temporal modeling beyond simple timestamps
  • FOAF — For detailed person/organization descriptions
  • DCAT — For dataset catalog metadata with provenance
  • Dublin Core — For basic metadata (title, creator, date)
